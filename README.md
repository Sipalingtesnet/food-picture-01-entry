# food-picture-01 v2: Tonkotsu Ramen Noodle Pull

A photorealistic tonkotsu ramen noodle pull: wooden chopsticks lifting tall glossy noodles, a soft-boiled egg with dripping golden yolk, chashu pork, and rich creamy broth under warm golden light.

`main.py` deterministically copies `entry.png` to `/output/entry.png` (or `MAKEFUN_OUTPUT_DIR`), verifying sha256 hashes. Standard library only, zero network dependencies.
